# Unit verification

SWE.4 checks implementing units against the [detailed design](../swe.3-detailed-design/index.md).
Scope: bounded reads, indexing, detection, patterns, typed errors and [insight analysis/publication units](01-verification-measures.md#insight-units).

[Measures](./01-verification-measures.md) identify executable checks/assertions.
[Shared strategy](../verification/01-strategy.md) defines selection and result recording; [fixtures](../verification/02-fixtures-and-environments.md) describes setup.
Linked measures do not imply fresh passes.
