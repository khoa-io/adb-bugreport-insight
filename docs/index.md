## Reading paths

- Maintenance: requirements → architecture → detailed design → verification measures.
- Evidence: traceability row → obligation → source → check → assessment and supporting execution record.
- Deferred scope: proposals; draft obligations do not constrain shipped behavior.

SWE.1–SWE.6 follow [lightweight ASPICE](../.agents/instructions/aspice.instructions.md).
